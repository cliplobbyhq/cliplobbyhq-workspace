# CapCut workflow (about 10 to 15 minutes per clip)

Clip Lobby cuts every clip in CapCut. Start on CapCut Free; move to Pro ($19.99 USD a month or $179.99 a year) only if the AI clipping or caption features run out of free use.

## Two ways in

| Source | When | How |
| --- | --- | --- |
| **Short clip** (a streamer's top Twitch/Kick clip, under 2 minutes) | Fast daily posting, launch week | Download it and edit it straight in CapCut |
| **Long video** (a full stream or podcast on YouTube) | Finding moments nobody has clipped yet | Glasp transcript → Claude → CapCut clip brief → CapCut AI clipping. See [finding-viral-moments.md](finding-viral-moments.md) |

## Editing each clip

1. **Load it.** Import the clip or long video into CapCut. For a long video, give the AI clipping feature the `-capcut.md` brief from `clip-reports/`.
2. **Reframe.** Set the canvas to 9:16. Keep the streamer's face cam visible, with gameplay above or below it.
3. **Trim to the hook.** Start on the reaction, with no build-up. Aim for 15 to 60 seconds, ending on the punchline or reaction.
4. **Captions.** Use Auto captions, styled bold and word by word in the centre. Fix any misheard names.
5. **Hook text.** Add up to 6 words on screen for the first 2 seconds (from the brief, if there is one).
6. **Audio.** No added music over speech. Turn down in-game radio if it drowns the streamer.
7. **Export.** Export at 1080p. If you used a template, delete the CapCut logo clip at the end first.
8. **Post.** CapCut doesn't post for you. Upload to TikTok, YouTube Shorts, Instagram and X, using each app's scheduler where it has one, and add the campaign's required tags.
9. **Submit.** Submit each post's link to its campaign.

## Title pattern

"<Streamer> <reaction> at GTA 6's <moment>", e.g. "Kai Cenat loses it at GTA 6's first police chase".

## Clip types that work at launch, in order

1. First reactions: opening scene, first car stolen, first look at the map
2. Chaos: police chases, crashes, rampages that go wrong
3. Bugs and glitches
4. Streamers reacting to each other, or chat roasting them

## Learning CapCut

Practise on 2 or 3 clips over the weekend before launch. Build one caption style and one hook-text style, and save them as templates so every clip looks the same.
